# SeaL_ · карусели

Конструктор для Instagram: карусели, обложки, планировщик ленты, видеомонтаж.
Фирменный стиль — шалфей/молоко/графит, шрифты Playfair + Inter.

- Видеобэкенд (ffmpeg) — на VPS, `/opt/seal/app.py`
